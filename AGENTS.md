# Project Protection Rules

## 🔒 STABLE ZONE: NANO BANANA ENGINE (V5.0.0 & V9.0.0 GOLD MASTER)
The "Nano Banana" engine logic for **BLEND** code, **FREE** mode, **Anatomy Authority (Template & Custom)**, and **REALISTIC** style preset is declared FULLY STABLE.

### DO NOT MODIFY (CORE PIPELINE LOCK - MODIFICATION FORBIDDEN):
- Prompt Structure: **DUAL STAGE V5 / V9 (AI BEHAVIOR SHAPING)**
- `buildNanoPrompt` logic within `isBlend === true` branch and the new `FREE` mode structural flow.
- **REALISM BEHAVIOR** block and its specific tokens (Subtle asymmetry, micro-wrinkles, etc.).
- **V5 / V9 FINAL NEGATIVE PROMPT** (Hard Lock logic in the final output layer, minimal architecture).
- Metadata Injection Pipeline (Context Linking Fix V3.7/V3.8).
- Failsafe V2 validation logic for BLEND mode.
- `masterNegative` Hard Override logic in the final return block.
- **Anatomy Authority Logic**: The behavior of switching between Template Mode and Custom/Manual mode, including the correct merging and parsing of `AsianBodyProfiles` (`buildType` logic, etc.).
- **Conflict Rejection Gates**: e.g., rejecting `AUTO` Pose Mode when Anatomy is set to `MANUAL`.

### ALLOWED MODIFICATIONS:
- UI/UX improvements that do not break the underlying data flow.
- Performance optimizations (like image resizing) as long as they don't degrade analysis quality for these modes.
- Adding NEW models, templates, or modes (e.g., a new "Banana Pro" model, or adding more body profiles).

### CRITICAL:
Any changes to the core engine logic for Nano Banana, Anatomy Authority, or Master Prompts must be explicitly requested by the user and verified with extreme caution.
